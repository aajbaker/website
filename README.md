# aajbaker.com

Personal academic portfolio for Aaron Baker, PhD student in cognitive science at Yale University.

## Structure

- `index.html` — Home/about page
- `research.html` — Publications and research areas
- `other.html` — Teaching materials and miscellaneous
- `style.css` — All styles
- `script.js` — Mobile nav toggle
- `assets/` — Photo, CV, and diagram image
- `thanksgiving/` — Thanksgiving 2026 planner (unlisted web app at /thanksgiving/)
- `api/thanksgiving.js` — Vercel function for the planner's live sync (needs an Upstash Redis store connected to the project)
